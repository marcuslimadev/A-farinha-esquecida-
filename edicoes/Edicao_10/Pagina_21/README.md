# Página editorial

Pasta reservada para os assets e o texto desta página. A quantidade de imagens será definida pelo roteiro da cena, não por uma regra de uma imagem por página.

Arquivos previstos quando produzidos:
- `texto.txt` — texto da página/dupla para diagramação no Corel.
- `IMG_XX_*.png` — somente as imagens exigidas pelo roteiro, geradas para o enquadramento editorial planejado.
- `direcao.txt` — proporção, função, continuidade e observações de composição quando necessário.
