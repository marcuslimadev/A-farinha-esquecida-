## Regras de integridade

1. Não declarar uma fase concluída sem arquivo em `aprovadas/`.
2. Não reconstruir um rosto aprovado a partir de descrição textual quando a imagem original estiver ausente.
3. Não promover pranchas, contact sheets, imagens com texto ou gerações com metadados alucinados.
4. Usar a nomenclatura `PERSONAGEM_FASE_TIPO_VNN.png`.
5. Preservar cada versão candidata até haver decisão explícita de aprovação ou rejeição.

## Conjunto final

Há 36 imagens-base aprovadas: uma para cada fase atualmente autorizada dos 16 personagens nomeados que exigem representação visual. Todas são retratos individuais verticais, sem texto, pranchas, metadados visuais, objetos ou personagens extras. As variações cronológicas foram produzidas a partir de uma âncora facial do mesmo personagem para preservar a identidade.

`Armando` aparece apenas como nome do estabelecimento `Bar do Armando`; não recebe lock individual porque não atua visualmente como personagem. O vereador, marido de Teresa, permanece sem nome no cânone e deve ser definido apenas quando uma página exigir sua presença.
